1. PROJECT PURPOSE
------------------
NeoOrigins Localization provides LOW-PRIORITY fallback translations for Neo Origins / NeoOrigins and compatible add-ons.

Core rules:
- NeoOrigins is the MAIN mod translated by this project.
- Official upstream translations ALWAYS have priority.
- This project fills only keys absent upstream.
- If upstream adds an official translation, overlapping fallback keys must be removed/pruned.
- No localization is generated at runtime in Minecraft.
- Automated/generative translation assistance is used heavily, with structural audits and human direction. Do not present the translations as fully native-speaker-reviewed.

- Compare actual Minecraft locale data before deciding borderline regional variants.
